## طريقة الرفع على GitHub
1. أنشئ Repository جديد على GitHub.
2. ارفع كل الملفات كما هي داخل نفس المستودع.
3. من إعدادات المستودع:
   - ادخل إلى `Settings`
   - ثم `Pages`
   - ثم اختر الفرع `main`
   - واجعل المجلد `/root`
4. احفظ الإعدادات.
5. سيظهر لك رابط الموقع بعد التفعيل.
